# Juell PDF Reader for Android

**A fast, private PDF reader for Android phones and tablets, by Juell-Tech.**

Open any PDF from your files, Downloads, Drive, email or chat apps. Pages fit your screen; pinch or double-tap to zoom; search the whole document; page thumbnails; light and dark mode. Works offline, with no ads, no account and no tracking.

## Download

**[Download the latest version (APK)](https://github.com/Juell-Tech/juell-pdf-reader/releases/latest/download/Juell-PDF-Reader.apk)**

Requires Android 8.0 or newer. Juell PDF Reader will also be free on Google Play.

## Install

1. Open the download link above on your Android phone.
2. Open the downloaded file (from the notification, or the **Files** app's **Downloads**).
3. If Android says installing is blocked, tap **Settings**, turn on **Allow from this source**, then go back.
4. Tap **Install**. If Play Protect warns about an unknown app, tap **More details → Install anyway**.
5. Open **Juell PDF** from your apps.

Installed from here, the app updates by installing a newer download over it. If you later install it from Google Play, uninstall this copy first: the two can't replace each other.
